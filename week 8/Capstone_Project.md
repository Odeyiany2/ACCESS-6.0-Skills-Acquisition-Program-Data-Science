## **Final Capstone Project -  Supervised Learning & Live Presentation**
### **Overview**
This capstone project is designed to assess both your technical machine learning skills and your ability to communicate insights clearly.
You will select one dataset from the two provided and perform a complete supervised machine learning workflow, covering both classification and regression tasks.

By the end of this project, you should be able to:
- Prepare real-world datasets for modeling
- Build, evaluate, and tune multiple machine learning models
- Interpret model outputs and feature importance
- Clearly explain your methodology and findings

## **📂 Dataset Selection (Choose ONE)**
You must choose one of the following datasets:

### **Option 1: 🏥 Medical Insurance Cost Dataset**
This dataset contains medical insurance cost information for 1338 individuals. It includes demographic and health-related variables such as age, sex, BMI, number of children, smoking status, and residential region in the US. 
Link to the dataset - [_Click Here_](https://www.kaggle.com/datasets/mosapabdelghany/medical-insurance-cost-dataset)
You will work on:

   - **Regression Task:** Predict the cost of medical charges.
   - **Classification Task:** create a new column that differentiates high paying and low paying customers then build a classification model to predict it. 

### **Option 2: 📞 Telecommunication Churn Dataset**
This dataset contains customer demographics, service usage, and contract information for a telecom company. 
Link to the dataset - [_Click Here_](https://www.kaggle.com/datasets/blastchar/telco-customer-churn/data)
You will work on:
   - **Classification Task:** Predict whether a customer will churn (Yes / No)
   - **Regression Task:** Predict a numerical variable - Monthly Charges



## **🎯 Project Objectives**
By the end of this project, you should demonstrate the ability to:
  
  - Perform end-to-end supervised learning


  - Apply data cleaning, feature engineering, and preprocessing


  - Build and compare multiple machine learning models


  - Evaluate models using appropriate metrics


  - Interpret model results and extract business-relevant insights


  - Communicate findings clearly to a non-technical audience

## **🧠 Project Requirements (What You Must Do)**
**1️⃣ Data Understanding & Cleaning**

  - Load and inspect the dataset
  - Handle missing values appropriately
  - Identify and treat outliers (where necessary)
  - Correct data types
  - Clearly justify any data cleaning decisions

**2️⃣ Exploratory Data Analysis (EDA)**
  
  - Perform univariate and bivariate analysis
  - Use visualizations to explore:
  - Distributions
  - Relationships
  - Patterns and trends
  - Highlight at least 3 meaningful insights from your analysis

**3️⃣ Feature Engineering & Preprocessing**

  - Create new meaningful features (if applicable)
  - Identify categorical and numerical features
  - Apply:
       - Encoding for categorical variables
       - Scaling/normalization for numerical variables
  - Use pipelines where appropriate

**4️⃣ Model Building (Supervised Learning)**
You must build at least two models for each task:

  - Regression Task
      - One baseline model (e.g., Linear Regression)
      - One advanced model (e.g., Random Forest Regressor, Gradient Boosting, LightGBM)

  - Classification Task
      - One baseline model (e.g., Logistic Regression)
      - One advanced model (e.g., Random Forest, XGBoost, LightGBM)


**5️⃣ Model Evaluation**

- Use appropriate metrics:
  - Regression: RMSE, MAE, R²
  - Classification: Accuracy, Precision, Recall, F1-score, ROC-AUC
  - Apply cross-validation


- Compare model performances clearly


- Identify the best-performing model for each task


**6️⃣ Model Interpretation**

- Explain which features influenced predictions

- Use:


    - Coefficients (for linear/logistic models)


    - Feature importance (for tree-based models)


- Discuss what the model’s behavior means in a business or real-world context
