# **Week 1 - Introduction & Setup**

Welcome to **Week 1** of the ACCESS 6.0 Data Science Track!  
This week sets the foundation for your learning journey. You’ll get familiar with how the course is structured, what’s expected of you, and how to use the key tools you’ll need throughout this program.
