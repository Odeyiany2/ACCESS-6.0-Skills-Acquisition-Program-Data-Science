# 📊 WEEK 3 - Exploration & Visualization

Welcome to **Week 3** of the ACCESS 6.0 Data Science Track.
This week focuses on **understanding data deeply** through **Exploratory Data Analysis (EDA)** and **visual storytelling**.

By the end of this week, you should be able to **analyze a dataset, uncover patterns, detect anomalies, and communicate insights visually**.


## 🎯 Learning Objectives

### Session 5 — Exploratory Data Analysis (EDA)

By the end of this session, you will be able to:

* Perform **univariate analysis** to understand individual variables
* Perform **bivariate analysis** to explore relationships between variables
* Identify **outliers** and understand their impact on analysis
* Analyze **correlations** between numerical features
* Develop **business-driven questions** and test them using data
* Clearly document insights in a Jupyter Notebook


### Session 6 — Data Visualization

By the end of this session, you will be able to:

* Create effective visualizations using:

  * Bar charts
  * Histograms
  * Boxplots
  * Scatter plots
  * Time-series charts
* Understand **storytelling with data**
* Choose the right chart for business interpretation
* Communicate insights clearly to non-technical stakeholders

## **Assignment (Session 6)**
Given this dataset - [Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

## 💡 Tips for Success

* Focus on **insight, not just plots**
* Always ask: *“What does this mean for the business?”*
* Keep explanations clear and concise
* Use markdown cells to document your reasoning
