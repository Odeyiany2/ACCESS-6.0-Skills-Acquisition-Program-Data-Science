# **ACCESS 6.0 Skills Acquisition Program - Data Science Track**
Welcome to the **ACCESS 6.0 Data Science Track** - a hands-on learning journey designed to introduce students to the fundamentals of **data science, analytics, and applied machine learning**.  

This 8-week program is part of the **ACCESS 6.0 Skills Development Program**, organized by the Department of Accounting, University of Lagos. It is specially tailored for students with little or no prior experience in Data Science or Python.  

---

## 🎯 **Program Objectives**
By the end of this program, participants will be able to:
- Understand the **core concepts of Data Science** and its relevance to Accounting, Finance, and Business.
- Work confidently with **Python, Pandas, and data visualization libraries**.
- Build, evaluate, and deploy simple **machine learning models**.
- Use **GitHub** for collaboration and project management.
- Deliver a complete **end-to-end capstone project**, deployed on Streamlit.

## 🧑🏽‍💻 **How to Use This Repository**
1. **Fork** or **clone** this repository to your GitHub account.
2. Open the notebooks in **Google Colab** (recommended) or Jupyter Notebook.
3. Follow along during live sessions and complete the exercises provided.
4. Push your work to your personal GitHub repo after each session.
5. Explore the **Resources** section in each week’s folder for extra learning materials.

---

## 📚 **Program Outline**
| Week | Focus Area | Key Concepts |
|------|-------------|--------------|
| 1 | Introduction to Python & GitHub | Python basics, data types, Git/GitHub setup |
| 2 | Data Manipulation with Pandas | Reading, cleaning, grouping, aggregating data |
| 3 | Exploratory Data Analysis | EDA, Visualization, and storytelling with data |
| 4 | Feature Engineering | Data transformation, encoding, normalization |
| 5 | Regression Models | regression analysis, metrics, model interpretation |
| 6 | Classification & Evaluation | Logistic regression, decision trees, tuning |
| 7 | Model Deployment | Streamlit, GitHub Pages, model hosting |
| 8 | Capstone Project | End-to-end solution, presentation & wrap-up |

---

## 🌍 **Program Tools**
- **Google Colab** — for hands-on Python coding.
- **GitHub** — for collaboration and project submission.
- **Streamlit** — for deploying models as web apps.
- **Python Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

---

## 🏆 **Capstone Project**
At the end of the program, students will complete an **individual project** in one of two tracks:
1. **Regression Track:** ESG & Financial Performance Prediction  
2. **Classification Track:** Telecom Customer Churn Analysis  

Each project will be deployed as a **Streamlit app** and submitted via GitHub.
