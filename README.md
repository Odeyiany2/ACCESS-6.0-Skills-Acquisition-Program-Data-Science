# **ACCESS 6.0 Skills Acquisition Program - Data Science Track**
Welcome to the **ACCESS 6.0 Data Science Track** - a hands-on learning journey designed to introduce students to the fundamentals of **data science, analytics, and applied machine learning**.  

This 8-week program is part of the **ACCESS 6.0 Skills Development Program**, organized by the Department of Accounting, University of Lagos. It is specially tailored for students with little or no prior experience in Data Science or Python.  

---

## 🎯 **Program Objectives**
By the end of this program, participants will be able to:
- Understand the **core concepts of Data Science** and its relevance to Accounting, Finance, and Business.
- Work confidently with **Python, Pandas, and data visualization libraries**.
- Build, evaluate, and deploy simple **machine learning models**.
- Use **GitHub** for collaboration and project management.
- Deliver a complete **end-to-end capstone project**, deployed on Streamlit.
